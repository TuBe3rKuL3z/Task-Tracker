Project Dashboard & Task Tracker (Gantt Chart)
Красивый и современный таск-трекер с интерактивной диаграммой Ганта, разработанный на C# WPF (.NET Framework 4.8) с использованием библиотеки Material Design In XAML и локальной базы данных SQLite.

Приложение разработано для максимального удобства визуализации задач и управления проектами.

Основные возможности
📊 Диаграмма Ганта (Временная шкала): Удобное представление задач в виде скользящей 30-дневной шкалы. Задачи автоматически рассчитывают свои отступы и длину на основе дат начала и завершения.
🌓 Динамическая смена темы (Светлая / Темная): Мгновенное переключение тем одной кнопкой в заголовке с автоматической подстройкой всех элементов интерфейса (включая рамки, фоны диаграммы и иконки).
💾 Локальная СУБД SQLite: Все изменения мгновенно сохраняются в локальном файле базы данных tasks.db в директории выполнения приложения. Нет необходимости настраивать сервер бд.
📝 Интерактивные диалоговые окна: Удобные модальные окна для добавления и изменения задач с валидацией ввода (название не может быть пустым, дата окончания не может быть раньше даты начала).
🎨 Современный UI/UX (Material Design): Векторные иконки с высокой четкостью отображения на любых версиях Windows (включая Windows 10/11), адаптивные цвета кнопок и карточек, всплывающие детальные подсказки при наведении на полосы прогресса.
🖥️ Адаптировано для работы: Программа всегда запускается во весь экран (Maximized), исключая искажение сетки диаграммы Ганта из-за произвольного изменения размеров окна.
Скриншоты и дизайн
Интерфейс разделен на две части:
Слева: Список задач с кратким описанием, бейджем приоритета (Высокий/Средний/Низкий) и кнопками управления (Изменение, Удаление).
Справа: Временная шкала с полосами прогресса задач, отображающими процент выполнения.
Архитектура проекта
Проект построен по паттерну MVVM с использованием современного MVVM Toolkit:

Models/ProjectTask.cs: Модель задачи с расчетными свойствами для отображения на сетке.
ViewModels/MainViewModel.cs: Управление состоянием приложения, командами добавления/редактирования/удаления и сменой темы.
Services/DatabaseService.cs: Логика создания БД SQLite и выполнения CRUD операций.
MainWindow.xaml / TaskWindow.xaml: Разметка страниц и диалоговых окон с привязками к динамическим ресурсам Material Design.
Требования для запуска и сборки
ОС: Windows 7 / 8 / 10 / 11.
Среда выполнения: .NET Framework 4.8.
Среда разработки: Visual Studio 2022.
Основные NuGet-пакеты (восстанавливаются автоматически при сборке):
MaterialDesignThemes (v5.3.2)
MaterialDesignColors (v5.3.2)
CommunityToolkit.Mvvm (v8.4.2)
Microsoft.Data.Sqlite (v8.0.8)
Инструкция по сборке
Клонируйте репозиторий:
bash

git clone https://github.com/ваш-логин/Project-Dashboard.git
Откройте файл решения Project Dashboard.slnx (или Project Dashboard.sln) в Visual Studio.
Выполните восстановление пакетов NuGet.
Соберите проект (Build -> Rebuild Solution).
Запустите программу! В папке сборки автоматически сгенерируется база данных tasks.db с демонстрационными задачами.
